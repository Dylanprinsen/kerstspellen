# Kerstspellen

Spelletjes voor de familie met kerst. Gewone HTML/CSS/JS, geen build-stap.

- `index.html` laadt alles.
- `js/basis.js`: opslag, spelers, scores, schermen (nu alles op één apparaat).
- `js/app.js`: menu, spelers en scorebord.
- `js/spellen/`: één bestand per spel; een spel meldt zich aan met `registreerSpel(...)`.
- `data/`: de gegevens per categorie (Instagram-volgers, medailles).

Lokaal bekijken: open `index.html` in de browser.
Online: GitHub Pages vanaf de `main`-branch.
